# Sri Lankan Tourism Website

A beautiful, responsive landing page for Sri Lankan tourism featuring destinations, attractions, tour packages, and traveler testimonials.

## Features

- 🏝️ **Popular Destinations** - Explore Sigiriya, Kandy, Bentota, and Ella
- 🎯 **Must-See Attractions** - Ancient temples, wildlife safaris, tea plantations, and pristine beaches
- 📦 **Tour Packages** - Cultural heritage, complete tours, and adventure packages
- ⭐ **Traveler Testimonials** - Real experiences from visitors
- 📱 **Fully Responsive** - Works perfectly on all devices
- 🎨 **Modern Design** - Beautiful UI with smooth animations

## Technologies Used

- HTML5
- CSS3 (with CSS Variables)
- JavaScript (Vanilla JS)
- Responsive Design
- Modern Animations

## Project Structure

```
landing-page/
├── index.html      # Main HTML file
├── styles.css      # All styling and responsive design
├── script.js       # Interactive functionality
└── README.md       # Project documentation
```

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/TharukaJayaweera/landing-page.git
```

2. Open `index.html` in your web browser

3. No build process required - it's ready to use!

## Sections

- **Hero Section** - Eye-catching introduction with call-to-action buttons
- **Destinations** - Grid of popular tourist destinations with images
- **Attractions** - Key attractions with icons and descriptions
- **Tour Packages** - Three different tour packages with pricing
- **Testimonials** - Customer reviews and ratings
- **About** - Information about Sri Lanka with statistics
- **Contact** - Newsletter subscription form
- **Footer** - Links, contact information, and social media

## Color Scheme

- Primary: Teal (#0d9488) - Ocean/Water
- Secondary: Green (#059669) - Tea Plantations
